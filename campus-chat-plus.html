CAMPUS CHAT PLUS LAB

01 ONE CAMPUS

Every office bought its own AI.

Before: five offices, five contracts, five logins, and nobody can see what went where. After: one chat with every model, one sign-in, and one audit trail.

02 ONE BOX

Every model, one place.

@ a model or an agent. / a skill.

This is the composer on the left screen. Pick any model, hand the question to an agent, or run a skill such as /xlsx or /pptx. Counts are from the live picker on 26 September 2026.

03 AGENT MARKETPLACE

Build an agent once. Anyone adds it.

The institution builds an agent and publishes it to the Agent Marketplace. Nobody installs anything. Anyone adds it to their chat, and it shows up under @ next to the models.

04 EDUCAUSE INFO

Ask the conference. Get the day.

One agent, four kinds of source: an MCP server for the schedule, a knowledge base of speaker bios, an API for rooms, and a web crawler that rereads the conference site. The chips show which sources answered. The sessions are illustrative, so ask the live agent for the real ones.

05 GROUP CHAT

Bring people in. Bring the agent.

Add people brings a colleague into the thread. Both of them talk to the same agent, switch to a model with @, and run a skill with /. Nobody copies anything between tabs.

06 AGENTS CALLING AGENTS

One question. Three agents.

An orchestration agent is an agent whose sources are other agents. It splits the question, asks each agent for its part, and hands back one answer. Each agent keeps its own permissions.

07 ON YOUR WEBSITE

Same agent, on your website.

Publish the same agent as a web widget. Visitors with no account get the same answers from the same sources, and the institution still owns the agent.

08 TRY IT

Ask it yourself.

Open a saved Educause Info thread

Copy a question and paste it into the live chat on the left. Name a date, not "day two", because the agent counts the preconference days.
